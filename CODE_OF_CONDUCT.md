# Code of Conduct

## The Standard

Be direct about technical problems. Be respectful about people. Give evidence for a
disagreement.

This repository makes claims about software engineering. Those claims must survive a
challenge. A challenge with evidence is welcome and it is the reason that the repository
improves.

## Expected Behaviour

- Give a source for an empirical claim.
- Accept a correction when the evidence supports it.
- Describe a problem in the work, not a fault in the person.
- Assume that the other person wants a correct result.

## Unacceptable Behaviour

- Personal attacks, insults, or harassment.
- Discrimination on any basis.
- Publication of private information without permission.
- Repeated disruption of a discussion after a request to stop.

## Enforcement

Report unacceptable behaviour through a GitHub issue, or privately through the Security tab if
the report contains sensitive information.

I will review each report. The response can be a warning, the deletion of a comment, or a block
from the repository. The response depends on the severity and on the history.

## Scope

This code applies in the issues, the pull requests, and the discussions of this repository.
